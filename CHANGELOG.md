# Changelog

## 0.1.0-milestone1 (2026-11-21)

- Playable solo foundation: Living Shore hub, six locations + two portal destinations,
  The Salt-Grave Signal adventure with four endings.
- AI Game Master over any OpenAI-compatible endpoint; honest Offline Storyteller fallback.
- The Undertow System dice (app-authoritative), Omen Deck, Vigor/Nerve.
- SQLite persistence: campaigns, journal, quests, facts (visible/hidden), transcripts,
  dice log, event log, FTS5 search, export/import, database backups.
- Procedural WebAudio soundscape with three volume buses.
- QR/scanner input with strict allowlist + printable card generator.
- 50 pytest tests; browser-verified flows.
