# Fantasy Asset Library

100 photorealistic fantasy stills from the Multiverse Fantasy Asset Pack, plus four
OpenFilm atmospheric loops derived from MAG-001, ENV-010, TWN-002, and MAG-007.

## Paths

| Item | Path |
|---|---|
| Images + manifest | `client/assets/fantasy/` |
| Scene mapping | `client/assets/fantasy/scene-mapping.json` |
| Art Library UI | `client/js/art-library.js` |
| Loops | `client/assets/cinematics/videos/fantasy-*.mp4` |
| Catalog | `client/assets/cinematics/meta/game-catalog.json` |

## Rules

- Living Shore hubs keep established photoreal cinematics.
- **TWN-002 Copper Kettle does not replace Salt & Lantern.**
- ENV-010 may ambience the wreck; MAG plates support portals / Art Library.
- OpenFilm is not required at runtime.

## Install

```bash
git lfs install && git lfs pull
```
